# Learn from work

Read [portable Manual boundaries](../../references/portable-manual.md), [Manual Workflow](../../../../references/manual-workflow-contract.md), [human-first output](../../../../references/human-output-contract.md), [artifact protocol](../../../../references/artifact-protocol.md), and [learning contract](../../../../references/learning-contract.md) completely.

Treat this explicit invocation as human authorization only for bounded repository-guidance edits. Require the exact current achieved Schema-5 Root, Evidence, and Review chain. Call `workflow_status` with that chain before mutation and proceed only when `learning.eligible: true`.

Treat returned candidates as advisory until evidence is confirmed and current repository inspection proves them. Treat any trailing human instruction as one supplemental candidate, not a Root selector. Deduplicate chronologically and use the repository's existing native guidance conventions.

Preserve unrelated work, validate each changed guidance file, and keep repeated closeout diff-free. Report `Quick decision`, complete human `Details`, then the authoritative `Agent and machine contract` with each candidate, source artifact, destination, changed path, and verification. Do not change product code, grant future authority, or merge, push, publish, deploy, or install.
