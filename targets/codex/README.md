# Workflow for Codex

Use `$install-release` to install or update from the latest stable Workflow GitHub Release. The skill verifies the download and prepares the personal plugin source and Marketplace entry. Restart, Plugins Directory installation or refresh, cache verification, and a fresh task complete activation. For a first installation without the skill, use the [bootstrap prompt](../../docs/installation.md#install-from-your-harness).

Use `$plan-work` in Codex Plan mode, then the native Implement Plan action. Commission review, correction, and learning separately. Keep the approved plan and reports in the native task, and supply an explicit handoff when changing tasks.

Each Review offers confirmed reusable lessons through `$learn-from-work`. Carry all open candidates through reports and handoffs; a later invocation reconciles and can save all still-valid lessons together. Learning is optional, checks conflicts and later changes, and does not replace necessary corrections.

The package contains skills and reference documents. It requires no Workflow runtime, Node executable, hooks, or MCP support. Your host controls permissions and execution.
