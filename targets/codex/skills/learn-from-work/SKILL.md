# $learn-from-work

Read [Manual Workflow](../../references/manual-workflow-contract.md), [artifact protocol](../../references/artifact-protocol.md), and [learning contract](../../references/learning-contract.md) completely.

Treat this invocation as human authorization for bounded repository-guidance edits only. Treat all trailing text as one supplemental Learning, never a Root or Run selector. Require the exact current achieved Schema-5 Root/Evidence/Review chain and call Manual `workflow_status` with that chain before mutation. Proceed only when `learning.eligible: true`. Do not use Controller Runs, older Roots, provisional acceptance, hidden memory, or unattested subagent output as authority; Codex remains Manual-only.

Treat returned correction candidates as advisory until `evidence_confirmed: true` and current repository inspection confirms them. Add the full trailing instruction as one human-authored candidate when non-empty. Deduplicate chronologically and route each confirmed Learning using the repository's existing native guidance conventions. Preserve unrelated changes, validate every affected guidance file, and keep repeated closeout diff-free. Report each candidate, source artifact, destination, changed path, and verification. Do not publish, merge, or push.
