# Workflow 4 validation boundaries

Repository validation covers Schema 4, Config/Policy 2, Protocol 4, Strategy hash chaining, scope authorization, Dirty Baseline, task recipes, evidence calibration, Decision Ledger, model Pool selection, Verification Profile lifecycle, MCP/bundle parity, context budgets, links, and packaging.

It does not by itself prove live Cursor model availability, SDK enforcement, Marketplace installation, OS sandbox behavior, keychain access, real UI driving, or production dependency safety. Those require the separate certification runbook and an exact Capability Receipt Schema 3.

Until every hard capability is positive, supervised remains Shadow Mode. Autonomous remains disabled per Qualification Key. Missing live proof is reported as unavailable; it is never promoted from repository tests or reviewer opinion.
