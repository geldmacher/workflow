# Harness qualification runbook

Qualification is exact and narrow. It applies to one Harness Capability Receipt, workspace binding, policy hash, verification-intent hash, Qualification Key, and certified region.

1. Prove the harness can enforce Root authority, workspace binding, review read-only snapshots, evidence attestation, budgets, and cancellation.
2. Issue a time-bounded protected generic Capability Receipt.
3. Bind the exact Qualification Key and hashes in a human-approved autonomous Schema-6 Root.
4. Run representative supervised deliveries and retain protected evidence outside Workflow authority.
5. Revoke or requalify on harness, policy, workspace, or verification-intent drift.

Workflow never certifies a model, command, tool, framework recipe, worktree implementation, or retry strategy.
