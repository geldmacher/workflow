# Profiles

| Profile | Human authority | Harness capability |
|---|---|---|
| Manual | Approves Plan, implementation, each correction, each fresh Review, and learning. | Local unprotected observations may support outcomes. |
| Supervised | Uses the same human loop and three Review outcomes. | External Host Adapter may provide protected attestations and orchestrated execution. |
| Autonomous | Uses the same Review UX and bounded correction path. | Exact qualification may expand execution capability; missing qualification downgrades capability, not outcome vocabulary. |

All profiles use Schema 6 and the same Achieved, Correction needed, and Open points results. There is no final delivery-acceptance gate. Profiles never move concrete commands, tools, models, frameworks, retries, sandboxes, or worktrees into Workflow core.

Manual has the least infrastructure. Supervised and Autonomous enter Shadow when protected capability is unavailable or wrongly bound; ordinary host use remains free. Learning always requires a separate human action.
