# Profiles

| Profile | Human authority | Harness requirement | Delivery |
|---|---|---|---|
| Manual | Approves Root, implementation, correction, replan, and provisional decisions. | Optional generic capability; missing evidence stays provisional. | Fresh Review plus human decisions. |
| Supervised | Approves Root and final delivery. | External Host Adapter plus valid deployment- and workspace-bound generic Harness Capability Receipt. | Harness executes; human accepts. |
| Autonomous | Approves the Root and exact qualification boundary. | Supervised protection plus exact deployment-bound Qualification Key and matching hashes. | Only fully verified evidence may complete without final acceptance. |

All profiles share Schema 6 and the same PhaseRequest/PhaseResult boundary. None owns commands, tools, models, sandboxes, worktrees, retries, or framework-specific verification.

Manual has the least ceremony. Do not impose autonomous qualification on it. Supervised and Autonomous become Shadow Mode when the external Host Adapter or its capability is missing, expired, incomplete, or wrongly bound. A direct project Harness or self-hash cannot establish trust. Ordinary host use remains free.

Provisional Manual acknowledgement is ephemeral and non-qualifying. Failed required Checks cannot be accepted provisionally. Learning always requires a separate human action after verified delivery.
