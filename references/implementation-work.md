# Implementation requirements

Read the [working agreement](workflow.md) unless it is already in this task's context. Resolve the applicable plan, assignment, and material amendments. Inspect the repository before editing; clarify consequential gaps or contradictions. Expressly commissioned Dark Auto-Work authorizes its in-scope plan by the human goal assignment; standalone work needs an approved plan.

Before editing, follow the plan's continue, wait, or isolate choice in [concurrent work](concurrent-work.md). With no recorded choice, still read it when this checkout holds other in-flight work. Implement planned outcomes and pending north-star updates from explicit user decisions, preserving unrelated edits. Choose tools, steps and proportionate checks using project guidance. Fix bounded problems in this phase. If only `any`, a forced cast, the same workaround in several places, or unplanned parameters or state makes the plan fit, report that deviation instead of patching it in; that is usually a wrong architecture. New goals, permissions, dependencies outside scope or material tradeoffs need a human decision. Follow [project readiness](project-readiness.md) for direction, prerequisite or feedback gaps; repair commissioned setup and offer out-of-scope additions.

For explicitly accepted verifier creation or maintenance in the plan, follow [verification-work](../skills/verification-work/SKILL.md). Run the first required end-to-end trial at implementation close, with product and verifier ready. Preserve evidence through cleanup and report failed or missing necessary proof. An unaccepted suggestion authorizes no verifier edits.

Capture reusable learning candidates, reconcile inherited ones this work affects, and carry the open collection as the working agreement describes. Capture authorizes no guidance edits or Review confirmation.

After necessary checks, report the result, important changes, deviations, actual checks and results, working state, and remaining limitations. Do not claim an independent review or final acceptance. For standalone work, recommend a separately commissioned Review. In expressly commissioned Auto-Work, return the report to its independent review step and request no other phase.
