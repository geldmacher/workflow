# Review Schema 5

Fresh read-only Review stays task-local, separates executor claims from independently inspected evidence, and never upgrades proof. Cursor receives the exact approved Root/chain only through its protected same-conversation receipt; Codex and portable clients supply exact bytes. Legacy state, caches, handoff, byte-less IDs, and other tasks grant no authority.

Missing, unapproved, invalid, or ambiguous Root—or an unavailable, expired, replayed, or mismatched Cursor receipt—blocks before substantive Review. Give one remedy: restore and approve this task's Plan or create and approve a new one.

The reviewer directly runs or inspects planned Checks and supplies closed [Schema-1 input](work-review-input-contract.md). Manual `verified` needs matching method, directory, expectation, result, and repetition. A repository-writing required command is a Plan defect: do not execute it; block with `replan`. High risk or Hard Triggers require delivery and risk auditors, plus material design review.

`workflow_closeout` owns validation, repository observation, Evidence/Review identity, status, lineage, hashes, bytes, and rendering. Cursor consumes one matching receipt, ignores caller Root/artifact copies, and checks any supplied `root_plan_id`. Complete predecessors allow delta Evidence; missing history yields labeled full rebuild without delta lineage. Both artifacts return or neither does.

Caller paths and snapshots are non-authoritative. Ambiguous or out-of-authority work becomes a limitation or Finding. Failed required Checks yield blocked Review, never achieved.

Verified completes; provisional needs separate acceptance; failure blocks. Malformed input gets one field repair, then only Review blocks. Present outcome, meaning, limits, then traceability; the first three stand alone without implementation history or code knowledge. Final only when achieved; otherwise give a preliminary explanation and the [guide](https://github.com/geldmacher/workflow/blob/main/docs/manual-workflow.md#review-results-and-next-actions).
