# Review Schema 6

Review is fresh and repository-read-only. Workflow validates the exact Root and lineage before repository inspection; the harness alone inspects and supplies observations.

Workflow never interprets or launches execution choices. Harness unavailability limits this phase, not ordinary host use.

The stateless builder accepts closed Schema-1 input, exact predecessors, a complete disjoint subject/ambient path partition, and `supported|partial|unavailable|failed` Check observations. Missing required Checks become unavailable; optional Checks may be supplied or omitted. It returns Evidence plus Review atomically without repository access.

Presentation gives decision, reason, Check outcome, scope, one proof boundary, and exact action; complete details occur once below it. `blocked` affects only this snapshot.

The Skill selects `de` only for active German, decorates only the returned action, and renders output and exact artifacts once.

Invalid, stale, ambiguous, or incomplete input returns Shadow without artifacts. Hard subject violations clarify; ambient paths never block. Finding-free plus supported or verified required Checks ends `achieved`/`none`; supported proof stays provisional. Review never mutates.
