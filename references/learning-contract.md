# Learning closeout

Learning is separate human-authorized repository work after terminal finding-free Review. Exact lineage, current `supported` or `verified` evidence, and fresh repository confirmation may support bounded guidance.

Other chains are ineligible. Supported stays non-verified. Confirmation authorizes only the deduplicated guidance edit; learning never changes state, authority, publication, or automation.

Classify each confirmed candidate before mutation:

- Stable general guidance, invariants, or pointers may enter the repository's existing guidance convention after deduplication.
- Project-verifier commands, selectors, or feature-map drift become a future `verification-work maintain` candidate. Learning never edits `.agents/skills/verify-*`.
- Run-specific observations remain evidence only and are never persisted as guidance.

Verifier output cannot prove its own maintenance or a changed repository snapshot. Learning creates no evidence and no circular success claim.
