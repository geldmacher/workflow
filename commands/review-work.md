# /review-work

Designed for Cursor Ask Mode. The optional `wp-*` selects one Root explicitly; without it, use the currently active native Cursor Plan in this task. Read [work-review](../skills/work-review/SKILL.md) completely.

Invocation authorizes read-only assessment and, when justified, one proposed correction. It never authorizes correction execution.
