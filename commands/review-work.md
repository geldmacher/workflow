This command is designed for Cursor Ask Mode. Cursor's native mode sandbox is the authoritative non-mutation boundary; the command neither infers the mode from tool availability nor redefines its capabilities.

Assess the effective root, reuse supported delta evidence, and embed one checked `cp-*` when correctable. Return a concise result and one compact review; Cursor progress text and additional explanation are tolerated, while multiple competing Workflow artifacts are not.
