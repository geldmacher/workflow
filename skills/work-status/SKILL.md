# work-status

Read the [working agreement](../../references/workflow.md). Stay read-only. From the available plan, assignments, and reports, explain what is planned, implemented, reviewed, corrected, or still uncertain. Identify which documents and working state support the explanation. Do not manufacture a status from an identifier or assume that absent reports mean completed work. Distinguish a completed phase from achievement of the goal. Give a next step only when needed; ask for missing context precisely.
