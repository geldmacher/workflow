# work-status

Apply the [working agreement](../../references/workflow.md); read it if missing or uncertain. Stay read-only. Summarize documented progress; explaining a finding's reasoning uses [explain-work](../explain-work/SKILL.md), and judging current work requires a commissioned Review. From the available plan, assignments, and reports, explain what is complete and what remains uncertain. Identify the supporting documents and working state. Do not manufacture status from an identifier or treat absent reports as completion. Distinguish a completed phase from an achieved goal. If work remains, give the next useful action, who takes it, and why; ask for missing context precisely. Follow the documented phase outcome without starting another phase. If the goal is established as achieved, state that no further Workflow step is required.

For Auto-Work, name the active or pending mode, phase, consumed and remaining correction rounds, latest independent Review, missing acceptance or delivery evidence, and next actor where relevant. Repository checks, human acceptance, and delivery are distinct outcomes. A status question does not reset or cancel the assignment; do not infer a mode switch or completion from it.
