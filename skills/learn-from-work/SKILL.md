# learn-from-work

Read the [working agreement](../../references/workflow.md). This invocation commissions only bounded learning updates to project guidance. Require a completed review establishing the relevant outcome and check that its supporting observations still apply. If the basis or destination is unclear, ask specifically.

Inspect the current guidance and confirm candidate lessons in the repository. Persist only reusable, demonstrated knowledge, deduplicate it, and preserve unrelated guidance. Report run-specific observations without making them permanent rules. Use the project's existing destination and learning conventions; do not edit personal memory without an explicit request for that memory.

Do not repair product code or project verifiers as learning. Describe verifier drift as a future maintenance task. Report saved paths, the learning, and its supporting evidence. Learning does not authorize publication or another workflow phase.
