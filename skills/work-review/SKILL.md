Start fresh and repository-read-only. Read [protocol](../../references/artifact-protocol.md) and [review](../../references/review-contract.md); use the closed Manual schema.

Resolve the exact task Root/predecessors when available; fresh tasks need attachment. Cache, hooks, IDs, transport, or ambiguity grant no authority. Run local `validate-plan`, but a missing or invalid formal binding must not prevent repository inspection. Continue read-only as Shadow Review against the human plan text; Shadow creates no artifacts and cannot offer Correct Work.

Inspect every objective, boundary, Check, and limit. Separate outcome from proof; the harness owns inspection.

Supply the closed Schema-1 outcome (`achieved|correction-needed|open-points`), Findings, Open Points, repository observation, and Check observations. Use `presentation_locale: de` only when the active request is German, else `en`. Partition every dirty path exactly once as Root-subject or ambient; uncertainty is subject. Grades are `supported|partial|unavailable|failed`; author no IDs, hashes, attestations, or verified claims. `supported` needs a conclusive current-snapshot outcome; command presence, invocation, or a masked exit status is not enough. Every genuine limitation needs an Open Point with cause, evidence, impact, and one human question.

After inspection run local `build-review`. If it returns `check-observations-incomplete`, observe exactly the named missing Check IDs and retry internally. Continue only while the retry signature changes and progress is measurable; the same signature without progress becomes a concrete `no-progress` Open Point. Finding-free plus supported or verified required Checks is `achieved` with no action. Ambient paths are visible and non-blocking. Authority, environment, intent, or evidence limits become explicit Open Points.

Render `human_output` once. Decorate only `presentation.next_action`: `correct`→**Correct Work**; `human-assessment`→ask for a natural-language assessment of the named Open Points; `none`→no action. Add no independent assessment or postscript. Put each artifact once, unchanged and unquoted, in its own default-closed `<details>`. Shadow creates none. Never mutate.
