# verification-work

Apply the [working agreement](../../references/workflow.md); read it if missing or uncertain. Read the [verification guidance](../../references/verification-work.md). Use for work on concrete verifier instructions. Task-level coverage questions use [workflow-doctor](../workflow-doctor/SKILL.md); ordinary test execution needs no additional verification-work invocation. Default to read-only `inspect`, without starting the product.

For accepted `create` work, read [creation](./references/create.md). For accepted `maintain` or `maintain full` work, read [maintenance](./references/maintain.md). Planning may read the applicable reference to prepare the proposal; execution follows the shared guidance and applicable implementation or correction assignment.
