# implement-work

Apply the shared [implementation requirements](../../references/implementation-work.md). When fitting the plan would need `any` or a forced cast, the same workaround in several places, or parameters or state the plan did not anticipate, report that deviation from the plan instead of patching it in, then stop and hand back until the plan is corrected rather than implementing around it. When the plan records another branch or worktree, read [concurrent work](../../references/concurrent-work.md) before editing. In standalone work, resolve the human-approved plan and implementation instruction, then recommend a separately commissioned Review. In an expressly commissioned Auto-Work sequence, return the implementation report to its independent review step.
