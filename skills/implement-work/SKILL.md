# implement-work

Apply the shared [implementation requirements](../../references/implementation-work.md). When the plan records another branch or worktree, read [concurrent work](../../references/concurrent-work.md) before editing. In standalone work, resolve the human-approved plan and implementation instruction, then recommend a separately commissioned Review. In an expressly commissioned Auto-Work sequence, return the implementation report to its independent review step.
