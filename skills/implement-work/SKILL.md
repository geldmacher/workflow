# implement-work

Apply the shared [implementation requirements](../../references/implementation-work.md) and its architectural stop. When the plan records another branch or worktree, read [concurrent work](../../references/concurrent-work.md) before editing. In standalone work, resolve the human-approved plan and implementation instruction, then recommend a separately commissioned Review. In expressly commissioned Auto-Work, return the report to its independent review step.
