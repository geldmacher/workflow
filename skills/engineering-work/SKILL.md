# engineering-work

Read the [working agreement](../../references/workflow.md). With no verb or with `suggest`, inspect the assignment read-only and follow the [catalog's offer rules](./references/catalog.md#planning-integration). Explain useful alternatives and their intended phase, recommend the best fit, and include an explicit option to use none. If none helps, say so without manufacturing an offer. The catalog is enough for the offer; full method references wait for explicit selection.

`use <playbook-id>` or an explicit inline selection chooses the method. Recommendation, silence, and acceptance of a verifier offer do not choose a playbook. Read only the explicitly selected method references. Selection grants no additional permission: diagnostic work stays read-only; mutating work needs an applicable plan and an implementation or correction assignment. Preserve applicable existing authorization. Apply only selected methods where they help; they do not become a permanent mode or a required part of every plan.
