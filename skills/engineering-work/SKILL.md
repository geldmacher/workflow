# engineering-work

Read the [working agreement](../../references/workflow.md). With no verb or with `suggest`, inspect the assignment read-only and recommend a useful entry from the [catalog](./references/catalog.md), explaining its fit and intended phase. If none helps, say so.

`use <playbook-id>` or an explicit inline selection chooses the method. Read only the selected playbook's reference from the catalog. Selection grants no additional permission: diagnostic work stays read-only; mutating work needs an approved plan and an implementation or correction instruction. Preserve applicable existing authorization. Apply only the selected method where it helps; it does not become a permanent mode or a required part of every plan.
