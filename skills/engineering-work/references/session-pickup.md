# session-pickup

Use to resume or take over prior work from task references, supplied reports, or an identified repository state. The deliverable is a grounded resume point and a clear next assignment. Inherited context does not manufacture human approval or commission a new phase.

## Reconstruct only what the handoff needs

1. Locate the approved plan, current assignment, relevant implementation and review reports, open decisions, and prior next action. Use accessible task references or complete supplied text. Start with the overview and latest outcome, then read back to the decisions that affect pending work.
2. Keep access scoped to the supplied task and project. Do not glob through unrelated private conversations. Summarize long records with available tools while retaining useful source pointers; do not invent missing content from a title or summary.
3. Inspect the actual branch or worktree, current diff, and relevant history. Distinguish completed changes, uncommitted work, unrelated edits, and pending work. A pushed branch or a prior agent's statement is evidence of state, not proof of human authorization.
4. Compare inherited observations with the current repository and original goal. Reuse established work that remains applicable. Recheck affected claims when code, environment, evidence, or acceptance changed; avoid repeating everything solely to recreate a trail.
5. Resolve conflicting plans, missing consequential decisions, or unclear authority before dependent execution. Name the exact missing information. Continue independent read-only grounding when useful.
6. Identify the next outcome: resume the authorized execution, provide the already completed answer, reassess a changed conclusion, or explain a failed attempt. Select the relevant method for remaining work only within the current assignment. The receiving executor needs the approved plan and applicable reports, not just a playbook ID.

## Result

Explain where the prior work stopped, what was inherited, what changed or was rechecked and why, unresolved decisions, and the first useful resume action. Preserve references to the supporting evidence. Do not claim completion from an inherited passing self-report when the current artifact no longer supports it.
