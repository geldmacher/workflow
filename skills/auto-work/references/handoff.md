# Native phase handoff

Keep the assignment text unchanged or keep an exact reference to it. Copy the block mechanically, including time periods and exclusions:

```text
BEGIN PLAN AND BOUNDARIES
Plan/reference; verbatim criteria/time/scope:
Workspace/shell cwd from first call; read/list/search roots:
Write scope and every excluded source/action:
END PLAN AND BOUNDARIES
```

Outside the block, carry mode and approval state, settings, spent rounds, reports and raw check output, decisions, learning, and the next action. Collect allowed baseline contents or digests before Review or edits; a later state cannot prove an earlier interval.

Resolve absolute paths from the fixed [Auto-Work](../SKILL.md) package for this file, the [working agreement](../../../references/workflow.md), the host reference, and the phase rule: [Plan](../../plan-work/SKILL.md), [Implement](../../../references/implementation-work.md), or [Correct](../../correct-work/SKILL.md). Review adds [review-work](../../review-work/SKILL.md) and [reviewer](reviewer.md). Include applicable conditional rules. Keep this list across rounds and replace only the phase paths; never abbreviate paths or invoke installed aliases.

Retain this template before native dispatch:

```text
PHASE ONLY: <role>; return to coordinator, no further phases.
FIRST TOOL: <native wrapper/tool args: assignment + fixed package rules only,
absolute paths/cwd, per-call/outer response budgets; raw output destinations>.
<original block or exact first-read reference; resolved mandatory rule list>
<progress/settings; existing report/baseline paths (read in place);
new rule/check paths/owners; intact check bodies; report path>
```

FIRST TOOL follows the live [Codex](codex.md) or [Cursor](cursor.md) schema, and every Shell call sets the assignment cwd. The child checks the three supplied fields before repository access; with an exact reference, it reads that reference first. If a field is blank, it reads only the named rules at the supplied cwd, then returns the block unchanged and names the missing fields; it does not look up or fill in values. It reads all rules before diagnostics, AGENTS.md, or source. Inherited context adds no read roots. The child returns the original block or an exact copy, its report, and its proof.

Read retained reports and baselines in place. New rule and check outputs use native results or assigned temporary files outside the repository, with exact paths, owners, and rights; make no extra copies and grant no extra rights. Retain complete `cat` or `tee` output, not quotations. Use no shell substitution and no observer or transcript access. Without a permitted route, record the proof as missing and stop.

Reuse safe criterion checks intact through literal stdin or heredocs; retain the actual expected and received values and exit codes. Add no extra escaping.

Before transitions, compare the original rule and boundary bytes with the fixed sources, and check the actual calls and cwd. Recover truncated child output before source access; retained files alone do not prove full reads. Link the original outputs and any recovery. Gaps block PASS: repair them in the same child or stop. Never decrypt opaque prompts or substitute generated receipts for raw proof. Acceptance, completion, and delivery need a valid fresh Review and the necessary proof.
