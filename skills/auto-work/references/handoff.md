```text

absolute paths/cwd, per-call/outer response budgets; raw output destinations>.

Blank: only named rules at supplied cwd, then unchanged block/missing fields; no lookup/fill. Read all rules before diagnostics/AGENTS/source. Inherited context adds no roots. Return original block/exact copy, report, proof.

Retain full `cat`/`tee` outputs, not quotes. No shell substitution, observer/transcript access. No route: missing proof, stop.

Link original outputs/recovery. Gaps block PASS: same-child repair or stop. No decryption/receipt substitutes. Acceptance/completion/delivery need valid fresh Review/necessary proof.
