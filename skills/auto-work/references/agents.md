# Task-local agents

Before phases, also Dark, inspect native schema/catalog/settings/overrides; read [Codex](codex.md) or [Cursor](cursor.md).

Resolve four roles together: recommend available IDs/options by complexity/risk, never maximum effort by default. Offer acceptance, edits or one model; Correct may share Implement. Verification agents need a purpose; commands have no model. Complete selections need no repeat; choose inheritance/defaults explicitly.

Unknown availability: request IDs/settings or native definitions; input adds no fields. Await selection; retain selections/availability on resume/mode switches. Changes affect future phases.

Validate native type/model/settings/workspace/context/overrides. Use arguments or compatible definitions, never prompt-only choices. Unsupported settings, rejection or mismatches stop dependent work; request valid choices without dropping settings or substituting models. No config rewrites, substitute CLIs, harness switches or external model APIs.

Use entry [handoffs](../SKILL.md#handoffs) and [phase records](../SKILL.md#phase-records): upcoming choices never fill history; accepted arguments/IDs establish submission, not execution.
