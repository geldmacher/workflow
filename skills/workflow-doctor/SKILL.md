# workflow-doctor

Apply the [working agreement](../../references/workflow.md); read it if missing or uncertain. Use for task-level questions about verification readiness or coverage gaps. This is the read-only entry for `verification-work inspect`: apply the inspection in the [shared verification guidance](../../references/verification-work.md). Report task readiness, concrete gaps, evidence, and the next useful action. For broader setup or prerequisite gaps, apply [project readiness](../../references/project-readiness.md). Do not change repository files, start the product, create or maintain a verifier, or claim runtime success from inspection.
